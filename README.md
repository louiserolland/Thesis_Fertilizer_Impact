# Thesis – Fertilizer and Food Prices under a Strait of Hormuz Disruption

Bachelor's thesis (Economics & Data Science, University of St. Gallen).

**Research question (working):** How do fertilizer prices transmit to food prices,
and what happens to that link during a global supply disruption through the
Strait of Hormuz?

## Repository structure

```
data/
  raw/          original downloaded data – never edited by hand
  processed/    cleaned data produced by the code in src/
notebooks/      exploratory Jupyter notebooks
src/            reusable Python code (data loading, cleaning, models)
  config.py        ALL settings: URLs, series, dates, countries  (the only file to edit for data changes)
  data_sources.py  download + parse every source, one section per provider
  database.py      DuckDB: schema, writing (upsert) and reading (monthly_panel, catalogue, sql)
  extract.py       command line entry point: runs the sources and fills the database
  (planned)        models.py (OLS, VAR/SVAR, IRF, FEVD) · forecast.py (XGBoost) · plots.py
tests/          offline tests of the parsers and the database (python -m pytest -q)
outputs/
  figures/      charts generated by the code
```

## Setup

```bash
python -m venv .venv

```

## Getting the data

```bash
python src/extract.py                 # download everything (takes a few minutes)
python src/extract.py fao worldbank   # only some sources
python src/database.py                # list what is in the database
```

Every downloaded file is archived with its date in `data/raw/<source>/` (data vintages).
The database `data/processed/thesis.duckdb` is rebuilt from those downloads, so it is not tracked.

In a notebook:

```python
import sys; sys.path.append("../src")
from database import monthly_panel
df = monthly_panel(["fao_ffpi", "fao_cereals", "wb_urea", "wb_ngas_eu", "wb_brent", "dummy_hormuz"], real=True)
```

### Manual steps
1. **Baltic Dry Index** has no free API: export it from a library terminal (Bloomberg `BDIY Index`),
   save as `data/manual/bdi.csv` with columns `date,value`, then run `python src/extract.py manual`.
2. **Each year** the World Bank changes the document id in the Pink Sheet URL → update `WB_MONTHLY_URL` in `src/config.py`.
3. On the first run, read the warnings: if a provider renamed a column, the parser prints the available names.

## Data sources

| Dataset | Source | Key needed | Notes |
|---|---|---|---|
| FAO Food Price Index + 5 sub-indices | FAO | no | dependent variables, 2014-16=100, revised monthly |
| Urea, DAP, TSP, phosphate rock, potash | World Bank Pink Sheet | no | $/mt; check urea quote change (Black Sea → Middle East) |
| Brent, WTI, natural gas US/Europe, LNG Japan | World Bank Pink Sheet | no | energy controls |
| Maize, wheat, rice, soybeans, soy/palm oil, sugar | World Bank Pink Sheet | no | soybeans = low-nitrogen placebo |
| Kilian global activity index, US CPI, USD REER | FRED | FRED | demand control, deflator, dollar |
| ONI / RONI (ENSO), US PDSI | NOAA | no | weather controls |
| Geopolitical Risk Index | Caldara & Iacoviello (2022) | no | |
| Global Supply Chain Pressure Index | NY Fed | no | contains the BDI among its inputs |
| Daily transits Hormuz / Bab el-Mandeb / Suez | IMF PortWatch | no | continuous measure of the closure |
| Fertilizer trade (HS 310210, 281410, 310530, 310540) | UN Comtrade | Comtrade | Gulf exports + mirror imports; months of reporting lag |
| Baltic Dry Index | Bloomberg / LSEG (manual) | terminal | not redistributable |
